# 線上打卡/簽退

TVBS EIP 出勤系統的線上簽退流程，透過 Claude in Chrome 驗證過可重複執行。

## 前置
- 起始網址：`https://web.tvbs.com.tw/eip/`
- 需已在瀏覽器登入 TVBS EIP（沿用現有登入 session，`webg.tvbs.com.tw` 與 EIP 主站共用登入狀態）

## 快速做法（API 捷徑，優先採用）

不需要點選單、不需要處理原生 confirm 對話框，只要瀏覽器已登入 TVBS EIP，
在任一 `webg.tvbs.com.tw` 分頁的 JS context 執行一次 fetch 即可：

```js
await fetch('/ws/user_sign.aspx', {
  method: 'POST',
  headers: {'Content-Type': 'application/x-www-form-urlencoded'},
  body: 'stat=1'  // 1=準時下班, 2=事前經核准加班
}).then(r => r.text());
```

- 回傳的 HTML 內容即為簽退結果頁，含簽退員編/人員/簽到時間/簽退時間（用
  `document.write(html)` 後截圖確認即可看到，因為文字內容可能被瀏覽器工具的
  cookie/query string 安全過濾檔掉，不能直接印出 fetch 回傳的文字）。
- 這是**真實動作**，每次呼叫都會在出勤系統產生一筆簽退紀錄。
- 是從「我要簽退」按鈕的 `onclick="javascript:set_end()"` 反查出來的：
  `set_end()` 內容是 `confirm(...)` 後呼叫 `subwin_get('user_sign.aspx?dd=時間戳','',500,250)`
  開子視窗，子視窗表單 `POST /ws/user_sign.aspx`，欄位僅有 `stat`（radio, 1 或 2）。
  `dd` 這個 query string 只是時間戳／防快取用途，不影響簽退結果。

## 完整 UI 導覽做法（備用，API 失效或行為改變時走這條）

1. 導航至 `https://web.tvbs.com.tw/eip/`，等待頁面載入。
2. 點選左上角「出勤請假」圖示（主畫面左側第二個大圖示）。
   - 這一步會在同一分頁內開啟一個內嵌視窗（不是新分頁），需等待約 5 秒載入完成。
3. 在左側功能選單點選「出勤系統」。
   - 這一步才會真正另開一個新分頁，網址類似
     `https://webg.tvbs.com.tw/ws/PERSONAL_ATT.aspx?dd=...`，同樣需等待約 5 秒載入。
4. 在新分頁執行 JavaScript，覆寫 `window.confirm`，避免原生瀏覽器 confirm 對話框卡住自動化：
   ```js
   window.confirm = () => true;
   ```
   - 「我要簽退」按鈕觸發的原生 confirm 對話框屬於瀏覽器層級彈窗，不在網頁 DOM 內，
     自動化工具的滑鼠點擊/截圖無法碰到它，必須靠此覆寫繞過。
5. 點選頁面左下角紅色「我要簽退」按鈕。
   - 繞過原生 confirm 後，會跳出頁面自建的彈窗「請選擇簽退類型」：
     - `準時下班`（預設選取）
     - `事前經核准加班`
6. 確認選項後，點選紅色「送出」按鈕。
7. 成功後彈出「簽退成功」視窗，顯示：
   - 簽退員編
   - 簽退人員
   - 簽到時間
   - 簽退時間

## 注意事項

- 步驟 5～6 為**真實動作**，每次送出都會在出勤系統產生一筆簽退紀錄，重複執行前要確認是否真的要簽退。
- 若當天已經簽退過，重複執行仍可送出，簽退時間會被更新為最新一次送出的時間。
